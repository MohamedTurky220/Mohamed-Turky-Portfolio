# Mohamed Turky — Portfolio Website

## Files
- index.html — website structure and content
- style.css — responsive dark portfolio design
- script.js — smooth navigation

## How to run
Open `index.html` in any modern browser.

## What to customize
1. Replace the LinkedIn URL with your real profile.
2. Replace the GitHub URL with your real profile.
3. Replace `your.email@example.com` with your email.
4. Add real project screenshots later if needed.

The website was designed as a Portfolio and Personal Brand Starter Kit for the NTI assignment.
